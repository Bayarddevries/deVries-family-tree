# Fleury line — documents mentioning Florence Fleury

These documents were archived 2026-08-14 while researching Paula Elysse Fleury's family
(Paula ⚭ Bayard; father Gordon Fleury). They confirm that **Florence Fleury** was the wife of
**Charles Edward "Charlie" Fleury (1928–1996)** and thus Paula's paternal grandmother.

IMPORTANT: every mention below uses Florence's **married name**. None of these documents
reveal her **maiden name** (she is likely still alive, so no obituary/burial record exists).
